# Appointment App

MERN stack appointment application.

## Applications

- `apps/web` — Customer and Provider application
- `apps/admin` — Admin dashboard
- `apps/api` — Express REST API

## Shared packages

- `@appointment/types`
- `@appointment/validation`
- `@appointment/config`
- `@appointment/utils`

## Stack

- React
- Vite
- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- Zod
